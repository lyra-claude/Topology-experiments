## Pooled metric definition (the thing being decomposed)

`run_eumas_families.compute_diversity(rng, pop, n_pairs=20)` called on `np.vstack(islands)` (the pooled 5-island population, N=250). It is the **mean pairwise normalised Hamming distance** over the pooled population, estimated by sampling 20 random distinct pairs with the run's own `rng` stream:

```python
def compute_diversity(rng, pop, n_pairs=20):
    n = len(pop)
    if n <= 1: return 0.0
    total = 0.0
    for _ in range(n_pairs):
        a = rng.integers(0, n)
        b = rng.integers(0, n - 1)
        if b >= a: b += 1
        total += np.sum(pop[a] != pop[b]) / GENOME_LENGTH
    return total / n_pairs
```

This 20-pair sample is an **unbiased estimator** of the EXACT pooled mean pairwise Hamming distance over all C(250,2) pairs. The published ANALYSIS.md numbers are this sampled quantity. We decompose the exact quantity (noise-free) and separately confirm the re-run reproduces the sampled published number bit-for-bit.

## Decomposition identity (AMOVA / pair-count)

Because the metric is a **mean pairwise distance**, the matching identity is the pair-count partition of pairs into same-island vs different-island:

- N = 250 (5 islands x 50). Same-island pairs = 5*C(50,2) = 6125. Different-island pairs = C(250,2) - 6125 = 25000. Total = C(250,2) = 31125.
- w = 6125 / 31125 = 0.196787.
- **within_island** = mean pairwise Hamming over same-island pairs (equal to the mean over the 5 islands of each island's mean pairwise Hamming, since islands are equal size).
- **between_island** = mean pairwise Hamming over all different-island pairs.
- **pooled_exact = w * within_island + (1 - w) * between_island.**

This is exactly the law-of-total for a mean over a partitioned set of pairs; it matches the metric because the metric is that same mean (just sampled).
